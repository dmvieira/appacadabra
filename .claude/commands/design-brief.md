## Appacadabra brand identity

**Visual DNA:**
- Name derives from "Abracadabra" + "App" — magic, transformation, accessibility
- Colors: read `lib/theme.ts` for the current palette (primary, background, card, accent, mana)
- Typography: clean, readable — optimized for mobile density
- Iconography: magical but precise — stars, wands, sparkles used sparingly
- Overall feel: powerful tool that feels approachable, not intimidating

**Do nots:**
- No generic "AI blue" gradient aesthetic
- No clutter — every element must earn its space
- No visual metaphors that don't connect to the spell/magic theme
- Avoid heavy drop shadows or excessive gradients

## Brief format

### Purpose

### Target context

### Key message

### Accessibility requirements
- Minimum contrast ratio: WCAG AA (4.5:1 for normal text, 3:1 for large text)
- Color-blind safe: test against deuteranopia and protanopia
- No information conveyed by color alone

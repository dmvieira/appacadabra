## What Appacadabra is

- AI-powered Android app generator: user describes in natural language → full working HTML/CSS/JS app runs natively via WebView with native capabilities (camera, contacts, sensors, notifications, etc.)
- Magic metaphor: spells, mana, cast
- Monetization: mana credits (in-app purchase) consumed per AI generation
- Local-first, privacy-preserving — only the spell prompt leaves the device
- Target user: non-technical or semi-technical mobile users who want a working app without coding

## Competitor categories to cover

1. **AI app / code generators** — tools that generate working apps or code from natural language (e.g. Replit Agent, Lovable, Bolt, v0, Claude Artifacts, GPT-4o Canvas)
